Formulation optimizer

Prototype from an R&D rotation

Suggests a starting formulation to guide bench prototyping.

Prototype: a proof of concept from my Research Technologist rotation, not a production model. I built it on my own.

The problem

New formulations start at the bench from a blank canvas. The aim of this prototype was to give technologists a starting point instead: predict eight target attributes from the ingredients and their dosage, then search for a formulation that comes close to the targets they want.

The hard part was the data. There were only 40 past trials to learn from, described by 100 ingredient features. A model with more inputs than examples can fit the training trials almost perfectly and still predict new ones badly, so the shape of the data drove most of the design.

What I owned

I built the prototype on my own during my Research Technologist rotation, the first assignment of my rotational scholarship program. That covers the feature aggregation, the Random Forest models, the leave-one-out validation and the NSGA-II search.

Technologists supplied the domain knowledge for grouping ingredients.

How it works

Shrink the inputs

Rather than feed the model all of the original ingredient features, I grouped ingredients with similar functional roles into fewer, broader features. I worked out the groups by consulting technologists, so each group means something to the people who would use the result.

Predict the targets

Random Forest regression predicts the eight target attributes from the grouped features. To estimate how wrong it is likely to be on a new trial, I used leave-one-out cross-validation: each trial is held out in turn, the model is trained on the rest, and it predicts the trial it never saw.

Search for a balanced formulation

With eight targets, improving one attribute can worsen another. NSGA-II, an evolutionary multi-objective algorithm, uses the models to search for formulations that balance the desired target attributes and contextual inputs. The output is a suggested starting formulation for technologists to take to the bench.

Check one at the bench

I entered the target profile, and NSGA-II returned its five best candidate formulations. I picked the one whose predicted attributes had the least error against the targets, by RMSE and MAE, together with a technologist’s judgment. That formulation was made and tested. Its measured profile was broadly similar to the prediction, with differences consistent with the model’s expected error.

Decisions

Grouped features with technologists

100 features against 40 trials is a severe small-sample problem. Grouping ingredients by functional role cut the number of inputs, and doing it with technologists put their knowledge into the model instead of leaving the grouping to an algorithm.

Trade-off. The model now reasons about groups, not single ingredients, so it cannot tell apart two ingredients that share a group.

Leave-one-out instead of a held-out test set

With 40 trials, setting aside a separate test set would leave very few trials to learn from and very few to test on. Leave-one-out uses every trial for testing once while training on all the others.

Trade-off. It still rests on 40 trials, so the error estimate is itself uncertain. It tells me roughly how far to trust a prediction, not that the model generalizes.

Framed the output as a starting point

The output is a starting formulation for bench work, not an answer. Physical formulation work stays with the technologists; the prototype only proposes where to begin.

Evidence

  • 40 past trials and 100 original ingredient features.
  • Eight target attributes, predicted with Random Forest regression and checked with leave-one-out cross-validation.
  • One formulation suggested by the model was physically tested. Its measured profile was broadly similar to the prediction, with differences consistent with the model’s expected error.

How far to trust it. The dataset is small, and the physical check was a single test. A result within the expected error is encouraging, not proof that the model generalizes.
