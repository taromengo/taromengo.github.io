Survey NLP app

A first pass through 4,000 multilingual survey answers now takes under an hour, down from 1–2 working days.

A working internal application with a small group of users so far.

The problem

Market-insights teams run surveys across regional markets, so the open-ended answers come back in several languages.

Before anyone could read for themes, the answers had to be translated, analyzed for sentiment and reviewed, which took 1–2 working days.

What I owned

I developed the application: a Shiny for Python interface with several analysis pages, covering file upload, translation, sentiment scoring, phrase extraction and the comparison views.

How it works

Upload and pick the text

A user uploads a survey file and chooses which field holds the open-ended text. The app treats every other field as a filter, so the same file can be sliced by market, age group or segment later.

Translate in bulk

The app translates the answers into English in one bulk pass, with a model running locally. Everything after this step works on one language.

Score sentiment

Each answer is classified as positive, neutral or negative. When the app combines them into an aggregate score, it uses the entropy of each prediction’s class probabilities to give uncertain predictions less weight. An answer the model is unsure about moves the aggregate less than a clear one.

Find phrases and compare groups

The app builds bigrams and trigrams on the fly, keeping the word pairs and triples that pass collocation thresholds. Users then compare open-ended reactions across markets, age groups and demographic segments.

Decisions

Weighted sentiment by confidence

A plain average counts every prediction equally, including ones that have similar probability distributions. I used entropy-weighted aggregation instead, so the overall score leans on the predictions the model is confident about.

Trade-off. It changed the results only slightly, mostly by toning down extremes: most scores land between 0.3 and 0.7 on the 0-to-1 scale. This is a trade-off I accept to feel more confident in the reported sentiment score.

Let the file decide the filters

Rather than fix a survey layout, the app asks which field is the text and turns the rest into filters. The filters are what the market, age and segment comparisons run on.

Translate everything first

All answers are translated into English in bulk before any analysis, so sentiment and phrase extraction run on a single language for easier user analysis and tracing later on.

Evidence

For a large multilingual survey of 4,000 responses, the first pass of translation, sentiment analysis and review went from an estimated 1–2 working days to no more than one hour.
